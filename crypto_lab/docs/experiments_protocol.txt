CryptoLab
Протокол экспериментов

Учебная модель, не для реальной защиты.
Не является юридически значимой УКЭП.
TLS-модель не совместима с реальным протоколом.

1. Из корня проекта запустить python -m crypto_lab.cli.main all.
   Зафиксировать результаты в reports/final_report.md, подробности
   по классике, анализу, целостности и подписи в отдельных отчётах.
2. Найти русскую контрольную фразу и проверить её восстановление
   после сдвига 3. Сопоставить Атбаш, Полибия, Виженера, перестановку
   и учебный ротор на том же наборе. Для латинского Полибия J → I.
3. Сравнить частоты на коротком, среднем и длинном образцах.
   Оценить перебор по словарю. При равных баллах нужна дополнительная
   гипотеза о содержании текста. Большая выборка даёт устойчивее
   частоты, но повторение фрагментов способно искажать оценку.
4. Извлечь открытое сообщение и шифротекст из условных LSB-носителей.
   Изменить бит длины, затем отдельно бит нагрузки. Длина проверяется,
   а корректно декодируемая подмена нагрузки остаётся незаметной
   без сравнения с оригиналом. Проверить Кардано с заполнителем.
5. Сравнить SHA-256 до и после изменения документа. В AES-GCM
   изменить байт тега, зафиксировать отказ и отсутствие открытого
   текста на выходе.
6. Проверить исходный документ, документ с добавленным знаком,
   другой открытый ключ и изменённую подпись. Артефакты раздельны:
   signed_document.txt, signature.json и public_key.pem.
7. Пройти модель TLS и проверить 20 вымышленных строк журнала.
   Признаки служат поводом для проверки. HTTPS не означает атаку.
8. Запустить pytest. Сравнить ожидаемые проверки с фактическими
   результатами в test_results.txt. Сквозной запуск также создаёт
   три контрольных дефекта на копиях данных, затем проверяет
   корректные данные. Базовые JSON-файлы сохраняются.
